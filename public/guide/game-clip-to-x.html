ゲームのクリップをXに投稿する方法
（いらない中間部分だけ消す）

「良いプレイの前後が長くて、そのままだと投稿しづらい」。そんなときに、退屈な中間部分だけをドラッグで消して、Xにそのまま上げられるMP4にする手順です。動画編集は初めてでも大丈夫。所要時間は1〜2分です。

用意するもの

  • ゲームの録画クリップ（ShadowPlay / Xbox Game Bar / PS5 / AMD ReLive など、形式はだいたい何でもOK）
  • パソコンと、Chrome や Edge などのブラウザ
アップロードはしません。動画はあなたのPCの中だけで処理されます。重い動画をネットに上げて待つ必要はありません。

手順

  1. クリップを読み込むQuickTrimmer を開き、録画した動画を画面にドラッグ＆ドロップします。右上の「動画を選ぶ」からでも読み込めます。
  2. どこを消すか決める動画を再生して、残したい場面と、いらない場面を確認します。波形（音の大きさのギザギザ）を見ると、しゃべっている所・盛り上がっている所が一目で分かります。
  3. いらない所をドラッグで塗るタイムライン（動画の下の帯）の上を、消したい区間でドラッグしてなぞります。色がついた部分が、書き出しのときに削除され、残った部分が自動でつながって1本になります。間違えたら右ドラッグで取り消し、または「元に戻す（Ctrl+Z）」が使えます。
  4. （必要なら）長さを調整画面の「X（無料）目安」のバッジで、書き出し後の長さとサイズがXの上限（2分20秒 / 512MB）に収まるか確認できます。超えていたら、もう少しカットしましょう。
  5. X用に書き出す右上の「X用に書き出し」を押します（ショートカット Ctrl+Enter）。Xに上げられるMP4がこのPCに保存されます。
  6. Xに投稿するXの投稿画面を開き、いま保存したMP4（ファイル名の最後が _for_X.mp4）を選んで投稿します。QuickTrimmer が自動でXに投稿することはありません——書き出したファイルを自分で添付する形です。
画質について：カットするだけのときは再エンコードせず画質はそのままです。Xが対応していない形式（HEVCなど）や倍速・縦横比の変更をしたときだけ、X対応にするため自動で変換します。くわしくは HEVC・PS5のクリップの記事 を参照してください。

便利な操作

  • 倍速：「倍速」モードに切り替えてドラッグすると、その区間を2倍〜8倍速にできます（移動シーンの早送りに便利）。
  • 縦・正方形：「アスペクト」で 9:16（縦）や 1:1（正方形）を選べます。上下left/rightは黒帯で埋めるので、HUDやキルログが切れません。
  • 無音検出：音のない区間を自動でカット候補にできます。
