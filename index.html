        キーボードショートカット

        Space 再生 / 一時停止
        ← → 1秒戻る / 進む（Shift で 5 秒、Ctrl で 0.1 秒）
        I 現在位置を「開始」にマーク
        O 現在位置で「終了」してカット範囲を追加
        Esc マークをクリア
        P カット後プレビュー再生 ON/OFF
        Ctrl+Z 元に戻す
        Ctrl+Shift+Z やり直し
        Ctrl+Enter X用に書き出し（すぐ書き出す）
        Delete 再生位置にある範囲を取り消し
        Wheel タイムラインのズーム / Shift+Wheel パン

        設定

        これより小さい音は「無音」とみなす。小さくすると検出が緩く、大きくすると厳しくなる。
        これより短い無音は無視する。間延びカットなら 0.5〜1.0 がおすすめ。
        無音区間の前後をこの秒数だけ残す（息継ぎや微小な音を切らないため）。
        毎回これらが選択された状態で起動する。
        別のアプリ（ゲームなど）に切り替えていても、書き出しが終わったら気づけます。タブのタイトルは自動で点滅してお知らせします。チェックを入れると、デスクトップ通知（画面右下などに出るお知らせ）も出します（最初の1回だけブラウザの許可が必要です）。

        プライバシー・利用規約

        プライバシーポリシー

        • 動画はあなたの端末から出ません。選んだ動画はブラウザの中だけで処理され（ffmpeg.wasm）、サーバーへは一切アップロードされません。作者が動画の中身を見ることはできません。
        • 保存内容は端末の中だけ。プロジェクトの保存データや設定は、お使いのブラウザの localStorage にのみ残ります。これも外部には送信されません。
        • アクセス解析。表示回数や表示速度の集計に Vercel Web Analytics / Speed Insights を使っています。Cookie は使わず、個人を特定しない統計のみで、動画の内容は一切含まれません。
        • アカウント不要。登録・ログインはありません。
